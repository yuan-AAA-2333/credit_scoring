# 功能扩展待办清单

> 记录本项目未来可扩展的功能方向，供后续迭代参考。
> 当前状态：基础版本已完成，以下功能按优先级排序。

---

## P0 - 高优先级（面试作品加分项）

### 1. 在线打分 API
- **需求**：将评分卡部署为 REST API，输入客户信息 → 输出分数和风险等级
- **技术方案**：FastAPI / Flask + pydantic 数据校验
- **接口示例**：
  ```
  POST /score
  Body: { "annual_inc": 60000, "dti": 15.5, "grade": "B", ... }
  Response: { "score": 438.2, "decision": "人工复核", "probability": 0.23 }
  ```
- **价值**：展示工程化能力，面试时可现场演示

### 2. 自动化报告生成
- **需求**：一键生成 HTML / PDF 建模报告，含所有图表和指标
- **技术方案**：Jinja2 模板 + weasyprint / reportlab
- **报告内容**：数据概览、EDA图表、模型性能、评分卡表、决策建议
- **价值**：交付物更专业，省去手动整理

### 3. 配置文件化
- **需求**：将硬编码参数（IV阈值、分箱数、随机种子等）提取到 YAML/JSON 配置
- **技术方案**：PyYAML / pydantic-settings
- **价值**：非程序员可修改参数，展示"配置驱动"设计思想

---

## P1 - 中优先级（技术深度加分）

### 4. IV 阈值自动择优
- **需求**：当前固定测试 5 个阈值，改为网格搜索自动找最优
- **技术方案**：在训练集上做 5 折 CV，自动搜索 IV 阈值空间
- **价值**：展示自动化调参能力

### 5. 决策树最优分箱（替代等频分箱）
- **需求**：当前使用等频分箱，可升级为决策树最优分箱
- **技术方案**：sklearn DecisionTreeClassifier 训练浅树，叶节点即为分箱边界
- **价值**：分箱边界与违约率更相关，WOE 单调性更好

### 6. 更多模型对比
- **需求**：增加 SVM、神经网络、集成模型等对比
- **技术方案**：sklearn 全家桶 + 统一评估接口
- **价值**：展示对不同模型特性的理解

---

## P2 - 低优先级（锦上添花）

### 7. 支持多种数据输入格式
- **需求**：当前仅支持 CSV，扩展为 Excel / Parquet / 数据库
- **技术方案**：pandas 多格式读取 + SQLAlchemy

### 8. 模型监控与漂移检测
- **需求**：上线后监控模型性能衰减，检测特征分布漂移
- **技术方案**：PSI（Population Stability Index）、KL散度
- **价值**：展示生产环境运维意识

### 9. SHAP 可解释性
- **需求**：用 SHAP 值解释单个客户的评分构成
- **技术方案**：shap 库 + 瀑布图
- **价值**：比评分卡更细粒度的解释

### 10. 单元测试覆盖
- **需求**：为核心函数编写 pytest 单元测试
- **测试重点**：clean_fit/apply、WOE计算、评分卡一致性校验
- **价值**：展示工程规范意识
